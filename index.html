How it works

음식 사진 한 장으로 시작하세요

촬영 → AI 분석 → 운동 제안까지 3단계. 스마트워치만 있으면 어디서든 10초 안에 끝납니다.

  1. 01

    📸 촬영

    스마트워치 카메라로 음식 사진을 촬영합니다. 손목을 살짝 들어 한 컷이면 충분합니다.

  2. 02

    🤖 AI 분석

    칼로리와 영양 정보를 즉시 분석합니다. 온디바이스 모델이 1.2초 내에 결과를 돌려줍니다.

  3. 03

    🏃 운동 제안

    맞춤 운동 계획을 자동 제안합니다. 섭취량에 맞춰 소요 시간과 소모 칼로리를 계산합니다.

    Eat under 600 kcal

    대전에서 600kcal 이하로 먹기 좋은 곳

    오늘 기록한 칼로리를 확인했다면, 이제 어디서 먹을지 정할 차례입니다. 대전 주요 상권의 저칼로리 메뉴 유형을 지역별로 골라 정리했습니다. 카드의 버튼을 누르면 네이버 지도에서 해당 지역의 실제 영업 중인 식당을 바로 확인할 수 있습니다.

    네이버 지도 연동 방식 안내

    네이버 지도 지도를 페이지에 직접 삽입하려면 Client ID 발급과 도메인 등록이 필요하며, 이는 인증 정보라 정적 사이트에 넣을 수 없습니다. 그래서 이 데모는 네이버 지도 검색 딥링크 방식으로 연결했습니다. 카드의 버튼을 누르면 새 탭에서 네이버 지도가 열립니다. 상호·영업시간·실제 메뉴는 변동이 잦아 지도에서 최신 정보를 확인해 주세요.

    —

    kcal은 해당 메뉴 유형의 일반적 1인분 추정값이며, 실제 매장의 조리법·제공량에 따라 달라집니다. 특정 업체를 지정한 추천이 아니므로 방문 전 네이버 지도에서 영업 여부를 확인하세요.

    최근 7일 진행 리포트

      Architecture

      이 웹앱은 이렇게 동작합니다

      발표자료의 기능을 브라우저에서 그대로 체험할 수 있도록, 분석 파이프라인을 클라이언트에서 시뮬레이션했습니다.

      1. 입력

      샘플 음식 또는 업로드한 사진을 FileReader로 읽어 스캐너 뷰에 렌더링합니다.

      2. 추론 (시뮬레이션)

      이미지 해시를 시드로 사용해 재현 가능한 분류 결과를 만들고, 신뢰도·영양소를 산출합니다.

      3. 저장

      RESTful Table API(tables/meals, tables/goals)에 기록하고 로컬 폴백을 유지합니다.

      4. 시각화

      Chart.js와 SVG 링으로 실시간 누적, 식사 밸런스, 주간 리포트를 그립니다.

      본 페이지는 발표용 데모입니다. 영양 수치는 참고용 추정값이며 의학적 진단이 아닙니다. 실제 서비스에서는 온디바이스 NPU 추론과 식약처 영양 DB를 사용합니다.
